✨ 歡迎使用！從 0 開始建立您的倉儲

只需 3 個步驟，即可完成您的專屬倉儲控管系統建檔：

第 1 步：設定企業與倉庫名稱

第 2 步：設定第一個倉庫區域格局

第 3 步：連接「客戶自己的 Supabase」

🔐 V53 不再使用共用登入伺服器。這裡輸入的 Supabase 將同時負責：登入 / 註冊 / 管理員 / 操作員 / 倉庫資料。
例如：https://xxxx.supabase.co

🔗 分享系統設定給其他裝置

其他裝置掃描 QRCODE 或開啟連結後，會自動套用本系統目前的品牌、倉庫格局與資料服務（雲端）設定，直接進入登入畫面，不需重新輸入設定。帳號登入／註冊使用客戶自己的 Supabase Auth；設定分享只會帶入專案 URL/Key，所有帳號與倉庫資料仍屬於客戶自己的 Supabase 專案。

⚠️ 此連結包含資料服務連線金鑰，請僅分享給信任的內部裝置或人員，切勿公開發布。
